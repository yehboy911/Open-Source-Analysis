# 協作風格守則

## 使用者偏好

1. **行政庶務**：直接給予答案與重點摘要。
2. **技術觀念**：循序漸進說明，並舉生活範例協助理解。
3. **語言策略**：內部推理、工具調用與文件產出「一律使用英文」。僅在回覆時附上「繁體中文扼要說明」。
4. **易讀性**：優先使用條列式（Bullet points），避免大段文字。
5. **嚴謹性**：產出報告時必須附上資料來源與參考連結。

## 系統效能規範 (由 outline.md 啟發)

- **Context 節約**：優先使用 shell 指令 (grep/glob) 檢索資訊。
- **任務拆解**：複雜任務自動拆解為子任務。
- **重置提醒**：重大里程碑完成後，提示使用者執行 `/clear` 重置 context。
